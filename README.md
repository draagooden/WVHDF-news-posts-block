# WVHDF News Posts Block

A custom WordPress Gutenberg block built with ACF (Advanced Custom Fields) to display recent news posts in a responsive grid.

## Features
- **Responsive Grid**: Automatically shifts from 1 to 2 columns.
- **Dynamic Content**: Fetches posts based on selected categories.
- **Interactive "Load More"**: Revealing additional posts without page reload.
- **Customizable**: Adjustable section titles, background colors, and sidebar options.

## Technical Details
- **Framework**: WordPress ACF Blocks.
- **Styling**: Vanilla CSS using CSS Grid and Flexbox.
- **Interactivity**: Vanilla JavaScript.

## Files
- `block.json`: Block registration and metadata.
- `news-posts.php`: Server-side rendering template.
- `news-posts.css`: Layout and component styling.
- `news-posts.js`: Frontend interactivity.
- `acf-news-posts-block.json`: ACF field definitions (JSON export).
